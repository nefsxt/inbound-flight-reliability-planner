## ⚖️ License & Data Provenance (Included Datasets & Feeds)

The dataset in use for the deployed application is persisted in the Hugging Face Dataset repository: 
- https://huggingface.co/datasets/nefelisxt/inbound-flight-data

This dataset is an open-source, non-commercial compilation created strictly for personal portfolio and educational display. It is distributed under the **CC BY-NC 4.0** license.

The underlying data feeds are dynamically compiled from two public sources, adhering strictly to their non-commercial and research terms of service:

1. **Weather Telemetry (Open-Meteo):**
   * Distributed under Open-Meteo's free-tier usage license (restricted to personal, non-commercial applications under 10,000 daily API calls).
   * Underlying meteorological data models originate from global public data providers (e.g., NOAA, DWD).

2. **Aviation Telemetry (OpenSky Network):**
   * Data is retrieved from the OpenSky Network API, intended for academic, hobbyist, and open research purposes.
   * If reusing this aggregated slice, please cite the OpenSky framework:
     > Matthias Schäfer, Martin Strohmeier, Vincent Lenders, Ivan Martinovic, and Matthias Wilhelm. "Bringing Up OpenSky: A Large-scale ADS-B Sensor Network for Research". IPSN 2014.
